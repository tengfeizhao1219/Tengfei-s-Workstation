# 🧠 智能网页总结浏览器插件

## 🎯 项目概述
**智能网页总结插件** - Chrome浏览器扩展，使用AI自动分析网页内容，生成简洁摘要和关键要点。

## ✨ 核心功能

### 1. 智能内容分析
- 🔍 **网页内容提取** - 自动识别和提取正文内容
- 🧠 **AI摘要生成** - 使用大语言模型生成简洁摘要
- 📋 **关键要点提取** - 识别文章的核心观点和结论
- 🏷️ **标签自动生成** - 基于内容生成相关标签

### 2. 用户体验优化
- ⚡ **一键总结** - 点击插件图标即可生成摘要
- 📱 **侧边栏展示** - 不干扰主页面浏览
- 🎨 **简洁界面** - 现代化设计，易于阅读
- 🔄 **实时更新** - 支持动态内容页面

### 3. 数据管理
- 💾 **本地存储** - 保存总结历史
- 📤 **导出功能** - 支持Markdown、文本格式导出
- 🔍 **搜索功能** - 快速查找历史总结
- 📊 **统计视图** - 使用频率和效果统计

## 🏗️ 技术架构

### 前端（浏览器扩展）
- **Manifest V3** - 现代Chrome扩展架构
- **React 18** - 用户界面框架
- **TypeScript** - 类型安全的JavaScript
- **Tailwind CSS** - 现代化CSS框架

### AI集成
- **OpenAI API** - GPT模型集成
- **本地模型** - 可选本地LLM支持
- **缓存机制** - 减少API调用成本
- **降级策略** - 网络不可用时的备选方案

### 数据存储
- **Chrome Storage API** - 本地数据存储
- **IndexedDB** - 结构化数据存储
- **同步功能** - 跨设备数据同步

## 🔧 技术细节

### 内容提取策略
1. **DOM分析** - 识别正文内容区域
2. **噪音过滤** - 移除导航、广告等无关内容
3. **结构解析** - 识别标题、段落、列表等结构
4. **文本清理** - 规范化文本格式和编码

### AI提示工程
```javascript
const prompt = `
请为以下网页内容生成简洁摘要：

标题: ${title}
内容: ${content}

要求:
1. 摘要长度在100-200字之间
2. 提取3-5个关键要点
3. 使用简洁明了的语言
4. 保持客观中立的态度

请按以下格式返回:
摘要: [摘要内容]
关键要点:
1. [要点1]
2. [要点2]
3. [要点3]
`;
```

### 性能优化
- **懒加载** - 按需加载AI模型
- **缓存策略** - 相同URL的重复总结
- **请求合并** - 批量处理多个页面
- **离线支持** - 基础功能离线可用
